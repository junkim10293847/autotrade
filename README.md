# 존박 국내주식 자동매매 v14

## 주요 기능
- 200만원 기본 투자한도와 실제 보유원가, 미체결 주문 예약액, 추가 투자 가능액 표시
- 증권사 계좌의 주문 가능 현금 별도 표시
- 종목별 평균 매수가, 보유수량, 매수원금, 평가금액, 평가손익 표시
- 신규 계획 컨펌 시 기존 보유 종목 유지 / 전체 교체 / 일부 교체 선택
- 신규 추천 종목을 종목별로 선택하거나 제외
- 매도 감시는 계획에 포함되지 않은 종목을 포함해 계좌 전체 보유 종목에 적용
- 매수일이 저장된 종목에 한해 14일 보유기간 정리 적용
- 교체 선택 종목은 매도 주문 후 계좌 보유 목록에서 사라진 것이 확인되면 신규 매수 재개

## 기본 매매 규칙
- 익절 +10%, 손절 -7%, 매수일 기록이 있는 종목은 14일 경과 시 정리
- 총 투자한도 2,000,000원 (plan.json의 max_total_krw로 변경 가능)
- 실제 보유원가 + 당일 미체결 주문 예약액이 투자한도를 넘지 않도록 매수 제한
- 비상 정지: plan.json의 paused를 true로 설정

## 파일 배치
- trade 저장소: index.html
- autotrade 저장소: bot.py, planner.py, plan.json, version.txt, notify.txt, .github/workflows/trade.yml, .github/workflows/plan.yml
- 기존 state.json, log.md, GitHub Actions Secrets는 보존할 것

## 주의
- 주문 가능 현금은 증권사 API가 반환한 계좌 값이며, 추가 투자 가능액은 200만원 투자한도에서 보유원가와 당일 미체결 예약액을 뺀 내부 한도다. 두 값은 의미가 다르다.
- 매도 손익 기록은 현재 코드상 주문 시점의 평균단가·현재가를 이용한 추정치이며 실제 체결 확정손익과 차이가 날 수 있다.
- 실전 전환 전 모의투자에서 충분히 검증할 것.
